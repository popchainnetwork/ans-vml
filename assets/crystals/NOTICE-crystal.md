# rdzeń crystal v1 — finite sourced snapshot, not universal coverage

Code and generator: Apache-2.0. Lexical dataset and API snapshots: Wiktionary contributors, CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/ . Attribution and revision URLs are in each leaf. Revision page histories identify contributors. This adapted lexical data is distributed separately under CC BY-SA, not relicensed Apache-2.0. Braille mapping reference: Wikipedia contributors, https://en.wikipedia.org/wiki/Polish_Braille (CC BY-SA 4.0). Unicode scalar and UTF-8 representations are computed, not translations. Morse encodes lossy ASCII rdzen, not exact Polish spelling.

Rebuild offline: `python3 build_crystal.py` in the directory containing the two API snapshots. Canonical leaves have only string values. Keys sorted recursively, compact UTF-8 JSON, no Unicode normalization; leaves sorted by canonical bytes and deduplicated. SHA3-256 leaf prefix 0x00, branch prefix 0x01, duplicate final odd node. Root commits all leaves including identity/license/scope, not JSON wrapper metadata. CLI recomputes counts and root. This is a local content index only, neither a mint nor signature.

English bridging is sense-specific and explicitly marked. Imported translation rows retain qualifiers/source wikitext; sharing an English gloss does not establish universal semantic equivalence. No claim of all languages, all senses or all writing systems. Missing IPA/romanizations are not guessed. Native-script/codepoints/UTF-8 leaves represent attested spellings; 561 form leaves do NOT mean 561 writing systems. Root changes when leaves change. Some IPA comes from rendered Wiktionary templates rather than raw revision data.

Character crystals use pinned Unicode 17.0.0 UnicodeData, Scripts, Blocks (Unicode-3.0 license; see UNICODE-LICENSE.txt). Five ordered character_reference leaves bind r,d,z,e,ń and their independent roots. UCD gives script/block/decomposition, not universal cross-script equivalents, which remain explicitly absent. Character Braille is Polish; ń Morse is labeled lossy. Both generator files and all UCD/API snapshots are required for offline regeneration.
