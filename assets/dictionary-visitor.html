// Genesis · Rust · XMSSMT / WOTS+ · PopChain

A dictionary where every entry is minted and signed.

Genesis is a native minted dictionary written in Rust. Words and the characters they are built from go through draft → validate → mint. Each mint is a native event inside a PopChain block, signed with hash-based XMSSMT / WOTS+ signatures. Anyone can check a public proof offline against the signer key they expect.

// 01 · Lifecycle

      
From draft to proof

      
The owner runs these steps with the ans dictionary CLI. Every step is a signed journal event, and retries with the same operation ID never mint twice.

    

    
    
      
  1. 1
    Draft
    Author a word or character. Its text and metadata are hashed into a content-addressed root (SHA3 Merkle).
    2. 
      
  2. 2
    Validate
    Rules are checked: a word may only use characters that are already minted.
    3. 
      
  3. 3
    Mint
    A signed native mint event is written as the payload of a PopChain block.
    4. 
      
  4. 4
    Inspect & prove
    Export a proof with its dependency closure. Anyone can verify it offline against an expected key.
    5.

    // 03 · Verify
    
      
    Check a proof yourself
    
      
    Paste or upload a Genesis proof (JSON) and the public key you expect it to be signed by. The server checks every signature, the block payload commitments and the dependency closure. Nothing is stored and nothing is signed.
    
    
    
    
    
      
    
        
    
        
        
    
          
          
          
          
        
    
      
    
      
    
        
        
        
    
          
          
        
    
      
    
      
      
    
    
    
    
    
      Same check on the command line
      
    ./bin/ans dictionary verify demo/oak.proof.json --expect-key "$EXPECTED_KEY"
    
      
    Get the key from a source you trust. A key copied from the proof itself proves nothing.

    // 05 · Honest limits
    
      
    What this is, and what it is not
    
    
    
    
    
      
    
        
    Works today
    
        
      
          
    • Native Rust dictionary with draft, validate, mint and inspect
      • 
          
    • XMSSMT / WOTS+ signed mint events inside PopChain blocks
      • 
          
    • Repeating an operation never mints twice
      • 
          
    • Word proofs carry the characters they depend on
      • 
          
    • Offline proof check: a wrong key or an edited proof is rejected
      • 
        
    
      
    
      
    
        
    Not claimed, not done
    
        
      
          
    • Experimental and not audited. Not for production use.
      • 
          
    • A signature proves who signed the bytes. It does not prove a meaning is correct.
      • 
          
    • One local signer. No consensus, no global names, no live network state.
      • 
          
    • Package is Linux x86_64 only.
      • 
          
    • Some older CLI commands (meaning, delegate, revoke, run) are not moved into the dictionary lifecycle yet.
      • 
          
    • This page is read-only. It cannot draft, mint or sign anything.
